# 약관 형광펜 데스크톱 리디자인 + 3D 펜 모션 — 설계

작성 2026-08-12. 브랜치: `kyeongmin`(원래 작업 브랜치 `feature/existing-policy-link`와 분리).

## 무엇을 하려는가

지금 데스크톱(900px 이상)은 `.app-shell`이 760px 고정폭 카드로 화면 가운데 뜨는 구조라,
모바일 화면을 그대로 재생하는 것에 가깝다. [Notion 제품 페이지](https://www.notion.com/ko/product)
톤(넉넉한 여백, 뚜렷한 타이포 위계, 미니멀한 다크/화이트 대비)을 참고해 데스크톱 레이아웃을
다시 짠다. 전 페이지를 한 번에 바꾸지 않고 **"약관 형광펜"(`/highlights`) 한 페이지를
플래그십으로 먼저 만든다** — 이번 요청의 핵심(형광펜 3D 모션)이 있는 곳이기도 하고,
여기서 만든 데스크톱 레이아웃 토큰을 나중에 다른 페이지가 이어받는 순서가 리뷰하기도 쉽다.

## 비주얼 방향

Notion의 미니멀·여백은 가져오되, 지금 앱의 "따뜻한 클레이 3D 아이콘" 정체성은 유지한다.
- 이 페이지에서만 배경의 떨어지는 아이콘 장식을 끄고 넓은 여백으로 정리
- 제목은 크고 굵게, 부제는 차분하게 — 위계를 지금보다 뚜렷하게
- `.app-shell`은 이 라우트에서만 폭을 넓힌다(다른 페이지는 지금 그대로 760px 유지) —
  `App.tsx`가 이미 `isHome`으로 `app-shell--home` 클래스를 조건부로 붙이는 것과 같은
  방식으로 `isHighlights` → `app-shell--highlights`를 추가한다
- 조항 원문 읽기 화면(원문 + 쉬운말 설명)은 데스크톱에서 좌우 2단으로

## 형광펜 3D 모션

**범위를 좁힌다**: 실제 관련도 하이라이트(`clause-relevant-mark`)는 조항마다 줄바꿈이
다르고 구간이 여러 줄에 걸칠 수 있어, 펜을 그 실제 구간에 기하학적으로 정확히 맞춰
움직이게 하는 건 깨지기 쉽고 이번 범위를 벗어난다. 대신 **페이지 히어로 타이틀 위에
지속 반복되는 장식용 모션**으로 만든다 — "이 사고와 관련된 부분, 노란색으로 한눈에"
문구 위를 형광펜이 좌→우로 쓸고 지나가면 그 자리에 노란 하이라이트가 칠해지고,
끝나면 하이라이트가 옅어지며 사라지고 다시 처음부터 반복한다(요청대로 "계속 지속").

**구현 방식**: 이미지 에셋 없이 **CSS만으로 3D**(`perspective` + `rotateX/rotateY` +
`translateZ`)를 써서 펜 모양을 만든다. `/public/3d/`에 마커·펜 에셋이 없어서(확인함),
새 라이선스 에셋을 급하게 구하는 대신 div 몇 개 + 그라데이션으로 기울어진 펜을 만들고,
텍스트 위를 지나가는 동안 `clip-path` 또는 너비 애니메이션으로 하이라이트 배경을 순차
공개한다. Three.js는 쓰지 않는다 — CSS 3D transform만으로 "기울어진 펜이 실제로 긋는"
입체감은 충분히 낼 수 있다고 보고, 만들어보고 밋밋하면 그때 Three.js 도입을 다시 논의한다.

## 되돌리기 쉽게 만들기

사용자 요청("다시 이전버전으로 돌릴 수 있게")에 따라 기존 코드를 고치지 않고
**더하는 방식**으로만 만든다.
- 기존 `.app-shell` 900px 규칙은 그대로 두고, `.app-shell--highlights`로 이 라우트만
  덮어쓰는 규칙을 추가(다른 페이지 CSS는 한 글자도 안 건드림)
- `ClauseHighlight.tsx` 안에서도 기존 로직(사고 연결 로딩, 검색, solo 모드)은 그대로
  두고 데스크톱 레이아웃 클래스만 조건부로 얹는다
- 새 컴포넌트(`HighlighterPenIntro.tsx` 등)는 파일 하나로 독립시켜서, 마음에 안 들면
  그 컴포넌트를 부르는 한 줄만 지우면 이전 화면으로 완전히 돌아간다
- 커밋을 작게 나눠서(브랜치 생성 → 레이아웃 → 펜 모션) `git revert` 한 번으로 각 단계를
  되돌릴 수 있게 한다
